# Epoch006 historical sample-rate forecast

**PLANNING_ONLY — NOT PERFORMANCE EVIDENCE.** This offline package forecasts
data availability and structural sample supply only. It does not accept PnL,
returns, win rates, expectancy, prices, or any outcome field. It never reads
epoch006 prospective evidence and is not an input to `PHASE3_ANALYSIS_GATE_V1`.

## Required historical source

The repository contains no historical multi-window market dataset. The tool
therefore accepts a frozen historical boundary-state JSON export generated by a
separate replay using exactly `QUANT_TREND_V1`, `QUANT_MR_V1`,
`SETUP_DETECTOR_V1`, and `SIMULATOR_V1`. Each 15-minute row must contain:

- timestamp, scoreability/rejection availability, and measurable data-gap flag;
- contemporaneous combined regime;
- frozen Quant Trend and Quant MR decision labels;
- frozen detector trigger, Trend/MR open-position state, explicit
  open-position suppression flag, and optional lock duration.

It rejects epoch006 as input and rejects any performance-named field.

## Calculations

- Rolling windows are 42 calendar days, sampled daily where a complete window
  exists; nominal scheduled supply is 4,032 boundaries/window.
- Quant trigger/no-trade frequency, trigger spacing, regime distribution,
  position suppression, and lock/streak distribution use only the frozen
  boundary-state inputs.
- Availability ESS calls the same lag-corrected ESS function used by the frozen
  Phase 3 gate, on the scoreable-boundary indicator. It is a planning
  sensitivity, not a substitute for pair-level primary-evidence ESS.
- Regime coverage reports rolling frequency of two trend states, two volatility
  states, and the frozen five-observation qualifying-bucket count.
- Historical LLM decisions and LLM position state are intentionally not
  fabricated. Each LLM-dependent pair reports a zero lower bound and a
  scoreable-Quant-state structural upper bound, with the assumption explicit.

## Interpretation boundaries

`COMFORTABLY_LIKELY`, `BORDERLINE`, and `STRUCTURALLY_UNLIKELY` are planning
labels based on the 10th percentile and median historical Quant trigger supply
against the unchanged frozen minima. They are not Phase 3 decisions and do not
alter thresholds, eligibility, simulator logic, right censoring, or the
primary evaluation.

## Current data limitation

Only synthetic fixtures and a single-boundary replay export mechanism are
present locally. A real historical coverage period, rolling distribution, and
structural-capability classification cannot be produced until a qualifying
outcome-free boundary-state export is supplied. No live epoch006 DB access is
needed for that work.
