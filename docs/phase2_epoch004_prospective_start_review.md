No Phase 2 provider request or paper order resulted from that cycle.

The candidate stores one integrity-hashed `PROSPECTIVE_START_ESTABLISHED` event in the existing append-only recovery-event table after the authorized worker reaches scheduler startup. Restart reuses the event and retains the existing audit-only downtime accounting for boundaries genuinely missed after that start. If prior evidence exists without this anchor, the worker fails closed instead of inferring a start from the old authorization time. Direct calls for a boundary before the anchor fail before snapshot, recovery, or provider processing.
